# 博物馆展签更换管理系统

馆内展品更换展签的全流程本地系统：策展人提交内容 → 编辑校对用语 →
保管员核对展品编号与事实 → 生成可打印版本（含二维码）→ 现场扫码证明新签装入正确展柜，
全程版本化、留痕可查。纯 Python 标准库 + SQLite，零第三方依赖。

## 启动

```bash
./run.sh            # 重置演示数据并启动，默认 8000 端口
./run.sh 8010       # 指定端口
```

打开 http://127.0.0.1:8000 。首次启动已内置演示数据：四个展品/展柜、
九张展签版本、六类问题记录，以及一次**装错柜被拒绝、复核后正确入柜**的扫码案例。

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 业务规则

1. **版本失效**：名称/年代/材质/正文/二维码任一修改都生成新版本；旧版校对结论
   自动标记为「已失效」，旧批注转为 stale；现场持过期标签扫码一律拒装。
2. **展柜唯一**：同一展柜同时只有一个有效展签（SQLite 部分唯一索引兜底）；
   换版时旧签在同一事务内撤下，保留完整撤换记录。
3. **角色分离**：策展人提交、编辑校对用语、保管员核对编号并做事实核对、
   现场人员扫码安装；**策展人不能批准自己提交版本的事实核对**；打印需双签通过。
4. **扫码复核**：二维码解析出版本与目标展柜，与现场展柜、台账三者比对；
   装错柜、二维码指向错误、过期版本、校对失效全部拒绝，无论通过与否均留痕。
5. **多语言并行**：中文、英文版本各自独立版次，互不顶替。

六类问题均有记录入口与演示数据：临时撤展、文字事实更正、旧展签未撤、
二维码指向错误、多语言版本缺失、印刷色差（模拟 ΔE，超 3.0 自动登记）。

## 界面

- 展馆白 / 石墨灰 / 小面积铜色；
- 展品目录与展柜列表同时显示**当前版次**与**待换版次**；
- 版本页原文与修订**并排对照**（改动字段与行级差异高亮）；
- 打印预览严格按真实标签比例 **120mm × 80mm（3:2）**；
- 顶栏可切换四种角色，界面按角色呈现可执行操作。

## 结构

```
app/db.py            SQLite 表结构（版本、校对、批注、打印、绑定、扫码、问题）
app/service.py       全部业务规则
app/adapters/qr.py   二维码模拟适配器（museum:// payload + 确定性点阵 SVG）
app/adapters/printer.py  打印模拟适配器（120×80mm SVG 样图、模拟色差）
app/seed.py          演示数据（六类问题 + 装错柜案例）
app/server.py        标准库 HTTP 服务与 JSON API
app/web/static/      单页界面
tests/test_rules.py  规则测试（22 项）
data/museum.db       SQLite 数据库（运行后生成）
data/label_proofs/   本地展签样图 SVG
```

## API 摘要

`GET /api/state` 全量数据；`POST /api/submit|annotate|review|print|scan|remove|issue`；
`GET /api/preview?vid=N` 真实比例预览；`GET /proof/<file>.svg` 样图。
