# 馆内展签更换管理系统

覆盖博物馆展签从策展提交到现场更换的全流程：**展品目录 → 展签版本 → 编辑校对批注 → 保管员编号核对 → 打印清单 → 现场扫码复核 → 撤换记录**。

零依赖（仅 Python 3 标准库），SQLite 持久化，二维码与打印机均为本地模拟适配器。

## 启动

```bash
./run.sh              # 初始化演示数据并启动 http://127.0.0.1:8000
PORT=8080 ./run.sh    # 自定义端口
```

右上角可切换操作人：**李策展 / 张策展（策展人）、文编辑（编辑）、古保管（保管员）**。

## 内置演示案例

| 展柜 | 场景 |
|---|---|
| C-101 青瓷莲瓣纹碗 | v1 已安装；**v2 已打印待换**；更换人员误扫 C-102 → **装错柜被拦截**（扫码流水可查） |
| C-102 铜鎏金腰带扣 | 编辑已校对后，策展人修改草稿正文（龙纹→摩羯纹）→ **校对结论失效**，须重新校对+核对 |
| C-103 石刻佛首 | 二维码指向错误、多语言版本缺失事件（草稿未入打印） |
| C-104 纸本花鸟册页 | 已打印安装，因借展**临时撤展**；另有印刷色差、文字事实更正、旧展签未撤事件 |

## 核心规则（均由测试覆盖）

1. **修改正文 → 校对结论失效**：批注与核对均锚定正文指纹（`content_hash`）；草稿改文后旧批注显示失效，已批准/已打印版本正文锁定，改内容须开新版。现场不能安装过期版本。
2. **同一展柜同时只允许一个有效展签**：`installations` 上的部分唯一索引 `WHERE end_time IS NULL` 强制；安装新版自动撤换旧版。
3. **角色分离**：只有编辑能写校对批注；只有保管员能做展品编号事实核对；**策展人不能批准自己提交的版本**（服务端硬校验）。
4. **扫码复核**：展签二维码（含目标展柜）与现场展柜码配对，不符即记 `matched=0` 并禁止安装，安装必须引用一条"匹配"的扫码记录。
5. 新版校对+核对齐全被批准时，同展品旧批准/打印版自动转为 `superseded`（展柜旧签保留到物理撤换，但不得再打印/新装）。

六类异常均可登记：临时撤展、文字事实更正、旧展签未撤、二维码指向错误、多语言版本缺失、印刷色差。

## 界面要点

- 展品目录的展柜行同时显示**当前版次**与**待换版次**；
- 版本详情把**原文与修订并排**，改动字段高亮；失效批注红色标注；
- 打印预览按真实标签比例 **100mm × 60mm** 渲染（模拟打印机输出 SVG 到 `data/samples/`，流水见 `printer.log`）；
- 配色：展馆白 `#fdfcfa`、石墨灰 `#2b2d2f`、小面积铜色 `#9a6a3a`。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

16 个用例覆盖：正文修改致校对失效、过期版本禁打/禁装、展柜唯一索引与自动撤换、
策展人自核拒绝、非角色操作拒绝、装错柜拦截、扫码配对冒用、二维码确定性与标签比例、六类异常登记。

## 目录结构

```
app/
  db.py         SQLite schema（含部分唯一索引）
  services.py   全部业务规则
  adapters.py   模拟二维码 / 模拟打印机（真实比例 SVG 样图）
  server.py     标准库 HTTP 服务 + JSON API
  seed.py       演示数据（含装错柜案例）
  static/       单页界面（无框架）
tests/          规则测试
run.sh          一条命令启动
```
